# UI System: Compose & Design

O BipSale utiliza **Jetpack Compose** de ponta a ponta com **Material Design 3**.

## 🎨 Design System
- Localizado em `:core:ui`.
- **Theming**: Implementação customizada de `MaterialTheme` para cores e tipografia da marca.
- **Components**: Botões, cards e layouts padronizados para garantir consistência visual.

## 📍 Navegação (Navigation 3)
- O projeto está na vanguarda utilizando **AndroidX Navigation 3**.
- As rotas são tipadas e gerenciadas centralmente no módulo `:core:navigation`.

## 📦 Bibliotecas Visuais
- **Material Icons Extended**: Para uma iconografia rica.
- **Coil**: Carregamento de imagens assíncrono.
- **ConstraintLayout Compose**: Para layouts complexos em telas específicas.
