# BipSale Project Structure Map

- **app**: Entry point, Hilt App, Global Theme.
- **core:data**: Repositories, Room DB, Retrofit API, Mappers.
- **core:domain**: Pure Kotlin. UseCases, Entities, Fiscal Logic.
- **core:navigation**: Type-safe routes and navigation logic.
- **core:ui**: Design System, Common Compose Components.
- **feature:sales**: Core POS selling screen & checkout.
- **feature:history**: Sales logs and transaction details.
- **feature:products**: Catalog and inventory management.
- **feature:qrcode**: Scanner and QR generation logic.
